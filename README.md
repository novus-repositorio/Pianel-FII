# Painel Fortaleza

Site estático (dashboard de inteligência imobiliária Fortaleza + link pro app de avaliação técnico-comercial). Protegido por senha (client-side). Fonte de código completa (scraping, cálculo financeiro) fica em repositório privado à parte -- este repo só tem o dashboard já pronto, com dado agregado por bairro.

Publicado via GitHub Pages a partir de `docs/index.html`.
